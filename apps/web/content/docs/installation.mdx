`create-newt-app` is a zero-friction CLI tool for bootstrapping great Next.js projects.
It spins up a modern `pnpm`-powered monorepo with a thoughtfully curated tech stack:

- [Next.js](https://nextjs.org): The React framework. The ecosystem to be in.
- [Nest.js](https://nestjs.com): Industry standard backend HTTP APIs.
- [better-auth](https://www.better-auth.com): Secure, flexible authentication and authorization baked in.
- [pnpm](https://pnpm.io/): Go full monorepo with `pnpm` to organize your project into `apps` and `packages`.
- [turbo](https://turborepo.dev/): Go turbo with `turborepo`. Faster, cachable, monorepo workflows.

It's simple and extendable, giving you everything you want and nothing you don't need.
From clean folder structure to sane defaults, you can start small and grow to enterprise demands.


```bash
pnpm dlx create-newt-app
```
