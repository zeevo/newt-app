`create-newt-app` scaffolds a full-stack TypeScript monorepo, wired together with `pnpm` and Turborepo:

- [Next.js](https://nextjs.org) frontend
- [NestJS](https://nestjs.com) backend
- [Better Auth](https://www.better-auth.com) shared across both apps
- [Kysely](https://kysely.dev) for typed SQL on SQLite or Postgres

Create a project:

```bash
pnpm dlx create-newt-app
```
